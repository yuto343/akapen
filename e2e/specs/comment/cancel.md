# コメント: 取り消す

## 概要

コメントの入力を取り消すと、撮った画像を捨て、枠を描く前の状態に戻る

## 前提

セットアップ済み、画面収録の許可ありで起動している。撮影対象のアプリ（Sample App）のウィンドウに枠を描き終え、コメントの入力欄が出ているところから始める。シナリオによって、確定済みの注釈が 0 件か 1 件ある

## 目的

囲む場所を間違えたときに、余計な注釈や画像を残さずにやり直す

## シナリオ

### 正常系

#### 注釈が 0 件のときに取り消すと、撮った画像は残らず、何も出ていない状態に戻る

期待される結果:

- 入力欄と画面上の赤枠が消え、ボタン類も消える
- アプリの状態で、何も出ていない状態になっており、注釈は 0 件で、書きかけの注釈もない
- 保存された画像で、撮った画像のファイルが消えている

してはいけないこと:

- 画像ファイルだけが置き場に残る
- コメントが空の注釈ができる
- ボタン類だけが画面に残る

#### 注釈が残っているときに取り消すと、それまでの注釈を保ったまま、ボタン類だけの状態に戻る

期待される結果:

- 入力欄と画面上の赤枠が消え、ボタン類は出たまま
- アプリの状態で、ボタン類だけが出ている状態になっており、注釈は 1 件のまま（コメントも変わらない）
- 保存された画像で、取り消した枠の画像は消え、それまでの注釈の画像は残っている

してはいけないこと:

- それまでの注釈の画像まで消える
- 書きかけのコメントが注釈として残る
- ボタン類まで消えて、残っている注釈が見えなくなる
