# akapen 設計

画面の上に赤枠とコメントを重ねていき、最後にまとめてAIへ渡すための macOS 向けツール。

2026-11-17 時点の設計。2026-11-18 に、初回版を使ってみて出た操作感の直し（ボタン類が出ている ⇔ 枠を描ける、確定後すぐ次の枠、ホットキーのトグル、`⌘C` / `⌘L`）を反映した。2026-11-19 に、撮る範囲を「枠の下のウィンドウ 1 つ」から「枠のまわりを画面に見えているとおりに」へ変えた。同日、確定済みの注釈と画像をまとめて消す操作（確認つき、`⌘⌫`）を追加した。2026-11-20 に、配布（Developer ID の署名と公証、GitHub Releases、Homebrew の tap、Sparkle による更新）を決めた。

## 目的と対象

- 画面上の気になる箇所を枠で囲んでコメントをつけ、それを AI エージェントに渡す。
- 主な貼り付け先は、ターミナルの CLI エージェント（Claude Code、Codex CLI など）と、デスクトップの GUI アプリ（T3 Code、Cursor など）。
- まずは自分で使う。ほかの人も入れられるように、Developer ID で署名・公証した版を配る（下の「配布」）。

## 操作の流れ

1. ホットキー（既定 `⌘⇧6`）を押すと、ボタン類（「すべて消す」「一覧」「copy prompt」）が画面の端に出て、同時にマウスが枠を描く操作（十字のカーソル）になる。ネイティブのスクリーンショット（`⌘⇧4`）と同じく、ボタン類が出ているあいだは下のアプリを操作できない。
2. ドラッグして離した瞬間に、枠のまわりを、画面に見えているとおりに撮影する（範囲は「キャプチャ」）。
3. 枠の横に入力欄が出るので、コメントを書いて確定する。入力欄は撮影の完了を待たずに出る（撮影・赤枠の描き込み・保存は裏で続き、写るのは離した時点の画面）。撮影が終わる前に確定したときは、終わるのを待ってから一覧に入る。
4. 確定すると注釈は一覧に入り、画面上の枠と入力欄は消える。すぐ次の枠を描ける状態に戻るので、2〜4 を続けて繰り返せる。
5. スクロールや画面遷移を挟みたいときは、ホットキーをもう一度押してボタン類を隠す（カーソルも普段どおりに戻る）。注釈は残っていて、次にホットキーを押すと同じ回の続きから描ける。
6. 「一覧」（`⌘L`）で注釈を見返し、コメントの修正や削除をする。一覧を開いているあいだは枠を描かない。閉じると枠を描く状態に戻る。
7. 「copy prompt」（`⌘C`）を押すと、プロンプトがクリップボードに入る。ボタン類が消え、注釈は空になる。回はここで終わる。

`Esc` は、いま出ているものを 1 段だけ戻す。

- 枠を描く状態: ボタン類ごと隠す（注釈は残る）。
- コメントを書いている状態: 書きかけを捨てて、枠を描く状態に戻る（隠さない）。
- 一覧を開いている状態: 一覧を閉じて、枠を描く状態に戻る（一覧でコメントを編集中なら、編集の取りやめだけ）。

「すべて消す」の丸いゴミ箱ボタン、または `⌘⌫` から確認を出し、確定すると、この回の確定済みの注釈と画像をすべて消す。元には戻せない。枠を描く状態・一覧の開閉は変えず、一覧を開いていれば空の一覧になる。0 件では使えない。確認は `Return` で確定、`Esc` で取りやめる。取りやめるとフォーカスを戻す。ボタン類が隠れたり注釈が 0 件になったら、答えを待たずに確認を下げる。

## ホットキー

- 1 つのキーで、ボタン類の表示と非表示を切り替える（トグル）。
  - ボタン類が出ていなければ、表示して枠を描き始める。注釈が残っていれば同じ回を続け、0 件なら新しい回を始める。
  - ボタン類が出ていれば（枠を描く状態・一覧を開いている状態）、隠す。注釈は残る。
  - コメントを書いている最中は何もしない（書きかけを失わないため）。
  - コピー完了の表示が出ている間に押すと、新しい回で枠を描き始める。
- 既定値は `⌘⇧6`。初回のセットアップと設定ページで変更できる。
- 既知の重複: Touch Bar のある Mac では、macOS の「Touch Bar のスクリーンショットを保存」（`⌘⇧6`）。
- ボタン類が出ているあいだ（枠を描く状態と一覧を開いている状態。コメントを書いている間と、一覧でコメントを編集している間は除く）は、`⌘C` で copy prompt（注釈が 0 件なら何もしない）、`⌘L` で一覧の開閉、`⌘⌫` で全削除の確認ができる（0 件なら何もしない）。修飾キーは `⌘` だけ。グローバルなホットキーとしては登録しない。

## 常駐と起動

- ログイン時に裏で起動しておく。Raycast と同じ形。
- メニューバーに小さなアイコンを置き、設定・アップデートの確認・終了はそこから行う。
- 「copy prompt」のあともアプリは終了しない。次にホットキーを押すと新しい回が始まる。
- ホットキーで隠しただけでは回は終わらない。注釈はメニューバーの件数に出たまま残り、終了しようとすると確認が出る。
- メニューバーから設定を開くと、設定のウィンドウを操作できるように、ボタン類は隠れる（注釈は残る。書きかけのコメントは捨てる）。「アップデートを確認…」を選んだときも同じ。
- ターミナル用の `akapen` コマンドは作らない。

## 初回のセットアップ

初めて起動したときに、次の 2 つを案内する。

- ホットキーを決める（既定値 `⌘⇧6` を提示し、その場で変えられる）。
- 画面収録の許可を出す。

## キャプチャ

- 撮るタイミングは、枠を描いてマウスを離した瞬間。
- 枠のまわりを、画面に見えているとおりに 1 枚撮り、そこに赤枠を描き込む。1 つの枠につき画像 1 枚。
- 写す範囲は、枠内に見えているウィンドウ全体をまとめて囲む矩形。
  - 「枠内に見えている」は、枠のうち手前のウィンドウに隠れていない部分と重なっていること。手前のウィンドウに隠れて見えていない後ろのウィンドウは入れない。
  - 見えている部分の面積が枠の面積の 5% 未満のウィンドウは入れない（端がかすっただけのもので範囲が広がらないように）。
  - 枠内に見えているウィンドウがなければ、枠の上下左右に 200pt ずつ足した矩形を写す（背景の壁紙が写る）。
- 範囲は枠を描いたディスプレイの中に切り詰める。ディスプレイ 2 枚にまたがる範囲をつなぎ合わせて撮ることはしない。
- 画面に見えているとおりに写すので、範囲に入ったほかのウィンドウの一部や影、壁紙もそのまま写る。akapen 自身の表示（覆う面・赤枠・入力欄）とカーソルは写さない。
- 指を離したら、枠が小さすぎる場合を除き、必ずコメントの入力に進む（ウィンドウのない所に描いても撮れる）。
- 一覧に出すアプリ名は、枠内に見えているウィンドウのアプリ名を、見えている面積の大きい順に重複なく並べたもの（例: `Notion, T3 Code`）。ウィンドウがなければ空。
- 高解像度ディスプレイの等倍では大きすぎるため、長辺に上限を設けて縮小する。上限値は実装時に、貼り付け先での読み取り具合を見て決める。

制約: ボタン類を出してから枠を描き終えるまでの間に、ホバーで出ている表示（ツールチップやホバー時だけのメニュー）は消えることがある。そうした一時的な表示は写せない場合がある。

## 注釈

- 種類は、四角い枠とコメントのみ。
- コメントを確定した注釈は一覧に入り、画面上には残さない。
- 注釈は、ボタン類を隠しても消えない。`copy prompt` で回が終わるまで残る。
- 一覧では、画像のサムネイルとコメントを並べ、コメントの修正と削除ができる。

## コメント入力

- 確定キーは設定で次の 2 通りから選ぶ。
  - `Enter` で確定、`Shift+Enter` で改行
  - `⌘Enter` で確定、`Enter` で改行
- 日本語変換中の `Enter` は変換の確定だけを行い、送信しない。その次の `Enter` で確定する。

## コピーされるプロンプト

画像をファイルに保存し、そのパスを含む文章をクリップボードに入れる。冒頭に定型文を置き、そのあとに「パス → コメント」を注釈の数だけ並べる。

```
I annotated the screen. Please address the comments below.
Open every image and check the area marked with the red frame before you start.

/Users/you/Library/Caches/akapen/20261117-1432/01.png
ボタンの余白が左右で違う

/Users/you/Library/Caches/akapen/20261117-1432/02.png
ここの文言を「保存する」に
```

- 通し番号と枠の座標は入れない。
- 定型文は 1 つだけ持つ。未編集なら言語設定の既定文を使う（2026-11-20）。一度編集すると言語を切り替えても同じ文を使い、空にすると言語追従へ戻る。
- 定型文の文面は設定ページで書き換えられる。「パス → コメント」の並びは固定。
- 形式は screencast-review の Copy Prompt（`viewer/src/lib/prompt.js`）を参考にした。

## 画像の保存先

- `~/Library/Caches/akapen/` に、回ごとのフォルダを作って保存する。
- 設定した日数より古いフォルダは、次回起動時に削除する。
- AI エージェントがあとからパスを読むため、コピー直後には消さない。

## 言語

- アプリ全体の言語設定を持つ。既定は英語で、日本語も用意する。
- 言語設定は、ボタンや一覧、設定ページ、初回のセットアップなどの表示と、定型文の両方に効く。
- 定型文は言語ごとに既定文を持つ。未編集の場合だけ、言語を切り替えるとその言語の既定文に変わる。
- 編集した定型文は全言語で共通の 1 つを保持する。空にして確定すると未編集へ戻る（2026-11-20）。

## 設定ページ

- 言語（英語 / 日本語。既定は英語）
- ホットキー
- 確定キー（`Enter` か `⌘Enter` か）
- 定型文（自由に書き換えられるテキストエリア。全言語で共通の定型文を編集する）
- 画像を残す日数

## 動き

- パネルの出入り・ホバー・一覧の開閉・セットアップのページ送りに、macOS の標準に寄せた短い動きを付ける（出るときはばねで、わずかに小さい大きさから。消えるときは速めのフェード）。
- ボタン類・一覧の行のボタン・設定・セットアップ・終了の確認の押せる部品は、ホバー中は指のカーソルにする（akapen がアクティブでないときも）。
- システムの「視差効果を減らす」がオンのときは、動きを不透明度の変化だけにする。

## 技術

- Swift のネイティブアプリ（AppKit / SwiftUI + ScreenCaptureKit）。
- `akapen.app` として作る。画面収録の許可はアプリ自身に付く。
- 外部のライブラリは、アプリ内の更新に使う Sparkle だけ。

## 配布

2026-11-20 に決めた。手順は `docs/RELEASE.md`。

- 配るのは、Developer ID で署名し、Apple の公証を通した `akapen.app` の zip だけ（dmg は作らない）。macOS 15 以降。
- 置き場は GitHub の `yuto343/akapen` の Releases。LP からも同じ zip を落とさせる。
- Homebrew の自前の tap（`yuto343/homebrew-tap`）からも入れられる: `brew install --cask yuto343/tap/akapen`。本家の homebrew-cask と Mac App Store には出さない。
- 入れたあとの更新は、アプリ内の Sparkle が受け持つ。
  - 裏で自動で確かめる（既定でオン。「自動で確認しますか？」とは聞かない）。
  - メニューバーのメニューに「アップデートを確認…」（英語では `Check for Updates…`）を置き、選ぶとその場で確かめる。
  - 更新の画面は Sparkle の標準のまま（akapen のデザインに合わせない）。
  - 自動で確かめるかの切り替えは、設定ページには置かない。
- 更新の zip には EdDSA の署名を付け、アプリは組み込んだ公開鍵で確かめてから入れる。

## 確認なしで置いた既定値

話し合いでは決めておらず、こちらで仮に置いた値。

- 確定キーの既定は「`Enter` で確定、`Shift+Enter` で改行」。
- 画像を残す日数の既定は 7 日。
- ボタン類は、ホットキーを押したときにカーソルがある画面に出す。
- 注釈が残ったままメニューバーから終了しようとしたら、確認を出す。

## 最初の版でやらないこと

- ブラウザの Web チャット（claude.ai、ChatGPT）への対応。ローカルのファイルを読めないため、別の出し方が必要になる。
- 矢印やフリーハンドなど、枠以外の注釈。

## 実装の最初に確かめること

- デスクトップの GUI アプリ（T3 Code、Cursor）に、パス入りの文章を貼っただけで画像が読まれるか。手で作った画像と文章で試す。読まれない場合は、クリップボードに画像ファイルも一緒に入れる方式に切り替える。

## 名前と配布についての調査結果

2026-11-17 時点。

- npm の `akapen` と crates.io の `akapen` は取得済み。`npx akapen` や `cargo install akapen` では配布できない。
- Homebrew と PyPI は空き。
- ドメインは akapen.com / akapen.jp が取得済み。akapen.dev / .app / .io / .sh / .ai は未登録に見えた（レジストラでは未確認）。
- 競合は意識しない。最も近い Pinpoint は実際に試したが、使いやすくなかった。
